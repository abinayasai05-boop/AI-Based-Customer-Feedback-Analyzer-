# 🤖 AI-Based Customer Feedback Analyzer

An AI-powered NLP project that analyzes customer feedback and automatically identifies whether the feedback is **Positive, Negative, or Neutral**.

The project uses a pre-trained **DistilBERT** sentiment analysis model to understand customer opinions and generate useful insights.

## 🚀 Features

- 🧠 AI-based sentiment analysis
- 😊 Positive, Negative, and Neutral classification
- 📊 Customer feedback statistics
- 📈 Sentiment visualization
- ☁️ Word cloud generation
- ⭐ Customer rating analysis
- 🔍 Individual feedback analysis
- 📁 CSV file support
- 💾 Export analyzed results to CSV

## 🛠️ Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- WordCloud
- Hugging Face Transformers
- DistilBERT
- PyTorch

## 📂 Dataset

The project uses a customer feedback CSV file containing:

- Customer ID
- Feedback
- Category
- Rating

Example:

```text
Customer_ID,Feedback,Category,Rating
C001,The product quality is excellent.,Electronics,5
C002,The delivery was extremely late.,Delivery,2
C003,Customer service was very helpful.,Customer Service,5
```

## ⚙️ How It Works

```text
Customer Feedback
       ↓
CSV Dataset
       ↓
Data Preprocessing
       ↓
AI Sentiment Model
       ↓
Sentiment Classification
       ↓
Positive / Negative / Neutral
       ↓
Charts & Customer Insights
```

## ▶️ How to Run

1. Open the project in **Google Colab**.
2. Install the required libraries.
3. Import the Python libraries.
4. Load the customer feedback dataset.
5. Load the DistilBERT sentiment model.
6. Run the sentiment analysis.
7. Generate charts and word clouds.
8. Export the analysis results.

## 📊 Output

- Sentiment distribution chart
